# GitHub Profile Configuration

## Goal
Maintain a cohesive,real production ,  high-impact GitHub profile for Kerolos Mounir.

The profile must feel like one consistent product, not a collection of independently generated sections.

## Required design workflow

Before making any visual change:

1. Use the Figma integration to inspect or update the profile design.
2. Use the UI UX Pro Max skill for UI/UX reasoning and review.
3. Treat the approved Figma design as the visual reference.
4. search as senior engineer on github and other design sites to make professional design , effects on text or in design itself
5. treat with this as a product and use find-skills skill if you need skills or tools to integrate
6. Verify GitHub rendering constraints before finishing.

Do not redesign individual sections independently.

## Layout rules

- Every section belongs to a visual panel.
- Section titles must be visually connected to their content.
- Titles are centered unless the approved Figma design says otherwise.
- Supporting text may use controlled text animation.
- Do not create detached headers.
- Do not introduce arbitrary new spacing, radius, colors, or typography.
- Reuse the same visual grammar across the profile.

## GitHub constraints

- README must remain GitHub-compatible.
- SVGs may contain safe SVG/CSS animation.
- Interactive links must remain real HTML links in README.
- Do not fake clickable regions inside embedded SVGs.
- Respect prefers-reduced-motion.
- Keep forks clearly identified as forks.
